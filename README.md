# Floria SelfHub

> **Your services. One place.**

A modern desktop dashboard for managing and monitoring your self-hosted services from a single interface.

Instead of keeping dozens of browser tabs open for Jellyfin, Navidrome, Docker, DNS, monitoring, and other services, SelfHub brings them together in one place.

## Features

- **Unified dashboard** — access your self-hosted services from one application.
- **Service integrations** — modular adapters make it easy to add new services.
- **Service information** — view sessions, libraries, health, monitoring, DNS, and other service data.
- **Tabbed interface** — keep each service in its own workspace.
- **Dark & light mode** — switch between themes to match your setup.

## Supported Services

| Service | Integration |
| --- | --- |
| Jellyfin | Sessions & library |
| Navidrome | Now playing & library |
| Uptime Kuma | Monitors |
| Gatus | Endpoint health |
| Speedtest Tracker | Internet speed |
| Cup | Image updates |
| What's Up Docker | Container updates |
| AdGuard Home | DNS & blocking |

> More integrations are planned.
